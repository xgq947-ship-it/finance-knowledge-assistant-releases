# 财务知识助手下载页

这里只发布已经签名校验的安装包，不包含源码。

## 下载安装

1. 打开 [最新版本](https://github.com/xgq947-ship-it/finance-knowledge-assistant-releases/releases/latest)。
2. Windows 电脑下载 `finance-windows-x64.exe` 并安装。
3. Apple 芯片 Mac 下载 `finance-mac-arm64.zip`。

首次安装后，应用每 30 分钟检查一次公开更新，不需要 GitHub 账号或 Token。
更新包验签通过后，会在北京时间凌晨 03:00–04:00 空闲时安装并自动重启。

安装后请在应用设置中配置企业微信机器人和 AI 模型 Key。
